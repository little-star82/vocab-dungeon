# 關卡島

一座島就是一週的單字。每座島一個資料夾，遊戲的地圖、選關、圖鑑、進度統計、排行榜都會自動算進去，不用改遊戲程式。

```
islands/
├── index.js            ← 島的清單（照學校進度由舊到新）
├── _template/island.js ← 新島的範本
├── w11/
│   ├── island.js       ← 這座島的單字、片語、關卡
│   ├── audio.js        ← 發音檔對照表（工具產生）
│   ├── audio/          ← 發音 mp3（選填）
│   └── img/            ← 單字圖片 webp（選填）
└── r0911/island.js     ← 複習考島（沒有自己的單字，跟別的島借題）
```

## 新增一座島

1. 複製 `_template` 資料夾，改名成島的代號，例如 `w12`
2. 改 `w12/island.js`：`id` 要跟資料夾同名，再填單字、片語、關卡
3. 在 `index.js` 加兩行：

   ```js
   import w12 from './w12/island.js';

   export const ISLANDS=[
     w11,
     w12,   // 新的放最後面，地圖上會排在最上面
   ];
   ```

4. 跑 `node tools/check_islands.mjs` 檢查有沒有寫錯
5. 本機開起來看一下（專案根目錄跑 `python3 tools/dev/server.py 8012`，開 http://localhost:8012 ），沒問題就 commit、push

## 單字表上的特殊寫法

單字表常有 `glove(s)`、`play football/ play soccer`、`give … a bath`、`face (clock)` 這種寫法。`en` 照單字表寫就好（斜線前後各留一個空白），畫面上會原樣顯示，另外兩個欄位視需要補：

| 欄位 | 用途 | 例子 |
|---|---|---|
| `sp` | 拼字題要拼的字。沒寫就用 `en`；`en` 裡有括號、斜線、… 而且沒寫 `sp`，這個字就不出拼字題 | `{en:'glove(s)', sp:'glove'}` |
| `say` | 要唸出來的字。沒寫會自動處理：`(s)` 唸成複數、括號裡的字不唸、斜線停頓一下 | `{en:'give … a bath', say:'give a bath'}` |

片語可以跟單字一樣放在 `words` 裡（`pos:'ph.'`），會出選擇、是非、聽力和「排出片語」；有例句的片語才放 `phrases`，會多出聽句子、片語填空那些問法。Week 08 是前一種，Week 11 是後一種。同一句片語兩邊都放也可以：放在 `words` 的那一筆會出現在它那一關，放在 `phrases` 的那一筆給小王出例句題，遊戲不會拿它當自己的干擾選項。

同一個字在兩關都要出現就寫兩筆（`d` 不同），不會出問題。

## 產生發音檔

島的資料寫好之後，在專案根目錄跑（`w12` 換成島的代號）：

```bash
uv run --python 3.12 --with kokoro-onnx --with soundfile tools/make_audio.py w12
```

它會列出遊戲會唸的每一段文字（單字、片語、例句、手寫片語題的句子），用 Kokoro-82M 的 `af_heart` 女聲合成，mp3 放進 `audio/`，對照表寫進 `audio.js`。之後改了單字再跑一次，只會補缺的。

跑完之後 `island.js` 要接上對照表（只需要做一次）：把範本裡的 `const audio={};` 那一行刪掉，在檔案最上面加 `import audio from './audio.js';`。

```js
import audio from './audio.js';
// …
export default { ..., audio, ... };
```

聲音跟 Week 11 是同一個（單字語速 0.85、整句 0.9）。第一次跑會下載模型，約 340MB，放在 `~/.cache/hyperframes/tts/`。Kokoro 是 Apache 2.0 授權，合成的聲音可以公開使用。

## 規則

- **關卡數不限**。地圖上的節點、地城的房間數都跟著 `stages` 的數量自動長
- **最後一關寫 `boss:1`** 就是小王，出綜合題：這座島每一章平均抽單字，加上 `bossQ` 的片語題（每句片語至少一題），全部混在一起考。抽幾題用 `boss:{words:8, phrases:6}` 調
- **單字的 `d`** 要對到某一關的 `id`，那個字才會出現在那一關
- **相反詞 `opp`** 要成對寫（big 寫 small、small 寫 big）。整座島有 2 組以上才會出「找相反詞」題，不夠的話遊戲會自動跳過這種題型
- **發音檔**沒有也能玩，會改用瀏覽器內建的英文語音。要有固定的聲音就跑下面「產生發音檔」那一行
- **圖片**放 `img/`，webp 格式、去背，單字加 `img:'檔名'`（不含副檔名）。有圖片的字會多一種「看圖選單字」的題型
- **`id` 上線後不要改**，島的 `id` 和關卡的 `id` 是存檔用來認關卡的，改了大家那一關的星星就對不上

## 題型（遊戲自動出，不用自己寫）

範圍固定是這座島的單字和片語，但每次玩的題型、選項、缺的字母、抽到的句子都重新隨機。

**單字題**（一關裡會盡量輪流出不同題型）

| 題型 | 條件 |
|---|---|
| 看英文選中文、看中文選英文 | |
| 是非題（這個意思對不對） | |
| 拼出單字、補上缺的字母 | 最多兩個字、14 個字母，而且只有英文字母 |
| 排出片語（把字排回去，混兩個別的字） | 兩個字以上 |
| 聽聲音選單字、聽聲音選中文、聽聲音拼出單字 | 關靜音時不出；沒有發音檔、裝置也沒有英文語音時不出 |
| 看圖選單字 | 單字有 `img` |
| 找相反詞 | 單字有 `opp`，且島上有 2 組以上 |

**片語題**（小王綜合題用）會從 `phrases` 自動變出這些問法：

- 片語意思（看英文選中文）、看中文選片語
- 片語填空（挖掉片語裡的一個字）
- 聽句子，選用了哪個片語
- 聽句子，把字排回去

後面兩種用的是 `ex` 例句裡真的有用到那句片語的句子，所以例句要寫完整。拆句子時會自動處理這些情況：

- `Mr.`、`Mrs.`、`O.K.` 不會被當成句尾
- 對話開頭的人名（`Polly:`、`Teacher:`、`A:`）會拿掉
- `get first (second) place` 這種括號裡的替換字不算在片語裡，片語當成 get first place
- 超過 10 個字的句子只出「聽句子選片語」，不出排順序

自動拆出來的句子不理想時，在那句片語加 `sents:['要用的句子']` 直接指定，例如對話只想用問句那一句。

選擇題的干擾選項會用別句片語，再加上放在 `words` 裡的片語（`pos:'ph.'`），所以片語只有一兩句的島也出得了題。

`bossQ` 是**選填**的手寫題，適合放自動出不來的題目，例如文法填空、情境對話、附中文翻譯的句子排列。有寫的話會跟自動產生的混在一起抽，選項順序每次都會洗牌。寫法見 `_template/island.js`：`kind:'mc'` 是選擇題，`kind:'order'` 是句子排列，`p` 標明是第幾句片語。

答錯的題目重考時會換一種題型或問法。

## 複習考島

考試範圍是前面幾週時，不用把單字再抄一遍，開一座「複習考島」跟那幾座島借題就好。範例是 `r0911/island.js`（Week 09 – 11 複習考）。

```js
export default {
  id:'r0911', review:true, from:['w09','w10','w11'],   // review:true ＝ 複習考島；from ＝ 考哪幾座島
  name:'三週試煉島', week:'複習考', dates:'Week 09 – 11', icon:'🌋', color:'#ff5c5c',
  rules:'開戰前顯示的規則說明',
  stages:[
    {id:'g09', from:['w09'], hp:20, ...},               // 這一關只考 Week 09，怪物 20 滴血
    {id:'final', boss:1, hp:42, charge:4,               // 最終關：42 滴血，蓄力 4 格放大招
     phases:[{from:['w09'],name:'Week 09'}, {from:['w10'],name:'Week 10'}, {from:['w11'],name:'Week 11'}], ...},
  ],
};
```

複習考島的關卡是**試煉模式**，跟一般關卡不一樣：

| 項目 | 試煉模式 |
|---|---|
| 題目 | 從指定的島一直抽，抽完重洗，中間穿插片語題，打倒怪物才停 |
| 怪物血量 | 關卡的 `hp`，跟題數無關 |
| 四人接力 | 答對一題換下一位勇者出招；小隊的愛心比單人多 3 顆 |
| 快答加成 | 每題有時間條，跑完前答對傷害 ＋1；答慢了不扣分 |
| 四人合體技 | 連續答對 6 題發動，傷害 4；連續 3 題一樣是必殺技，傷害 2 |
| 魔王階段 `phases` | 血量平均分成幾段，每一段考不同的島，換階段時魔王會變大、變色 |
| 魔王蓄力 `charge` | 每出一題蓄一格，蓄滿放大招「考卷風暴」扣一顆心（護盾擋得住）；發動必殺技或合體技會把蓄力清空 |

發音檔、圖片、圖鑑紀錄都跟著單字原本的島，所以複習考島不用另外產生發音檔。在複習考答對的字，原本那座島的圖鑑也會亮起來。

在 `index.js` 裡照考試的時間點排進去就好，例如 Week 12 那週考 Week 09 – 11，就排在 `w11` 後面、`w12` 前面。

## 戰鬥規則

- 怪物的血量照勇者的強度算（`dmgPerQ`）：目標是一關大約要答跟單字數一樣多的題。第一輪的字出完、怪物還沒倒，會再抽一輪（同一個字換一種題型）。答對一題扣 1
- 小王：要答的題數是綜合題題數的 1.4 倍（`BOSS_MORE`），而且每出 5 題放一次大招扣一顆心（`BOSS_CHARGE`）。發動必殺技會把蓄力清空，所以全部答對不會被打到
- 複習考的 `hp` 是 Lv1～9 的血量，等級高會照比例變多
- 連續答對 3 題發動必殺技，扣 2（`js/game.js` 的 `SP_DMG`），所以連擊越多越快過關
- 勇者最高 Lv50（`MAX_LV`），Lv10、20、30、40、50 各學一招新招式，傷害和回的愛心寫在 `HEROES` 的 `moves`，演出寫在 `SPECIALS`
- 答錯的題目會記進錯題本（存檔的 `miss`），key 是「島代號/單字」，片語是「島代號/~片語」。**改掉已上線的單字或片語的英文寫法，舊的錯題紀錄會對不上而被跳過**（不會壞，只是那一筆不再出現）
- `HEROES` 裡有 `hidden` 的是隱藏勇者，`hidden.lv` 是解鎖門檻：一般只看沒有隱藏的那幾位，加了 `all` 的要排在他前面的全部勇者都到。複習考的小隊固定四個人（隊長加三位一般勇者），隱藏勇者只有當隊長時才上場
- 關卡的 `enemy` 可以填骷髏（`Skeleton_Minion`、`Skeleton_Rogue`、`Skeleton_Warrior`、`Skeleton_Mage`）或可愛怪物：`Alien`、`Alien_Tall`、`Cactus`、`Crab`、`Cyclops`、`Deer`、`Demon`、`Ghost`、`GreenDemon`、`Panda`、`Skull`、`Tree`、`Yeti`、`Bat`、`Bee`、`YellowDragon`。打錯字會自動換成骷髏小兵。怪物的清單在 `js/game.js` 的 `MONSTERS`
- 換裝商城的商品寫在 `js/game.js` 的 `ITEMS`（裝備）和 `DYES`（配色），要改價格、加配色改那兩個清單就好；過關給多少金幣在 `clearCoins`
- 錯題洞窟不是一座島，不用在 `islands/` 加任何東西；它直接從所有島借題
- 答錯的題目一定會再出一次，必殺技不會把它跳過
